# Google Homepage Clone

This project is a clone of the Google homepage created using HTML, CSS, and JavaScript.

The project recreates the basic Google UI including:
- Google logo
- Search bar
- Navigation links
- Search buttons
- Footer section

## Features

- Responsive Google-like homepage
- Realistic search bar design
- Gmail and Images links
- Functional Google Search button
- "I'm Feeling Lucky" button
- Mobile responsive layout
- Hover effects and smooth UI

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Functionalities

- Users can type in the search bar
- Press Enter or click "Google Search" to search on Google
- "I'm Feeling Lucky" opens the first search result
- Gmail and Images links redirect to official Google pages
